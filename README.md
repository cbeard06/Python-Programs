## 🚀 How to Run Projects

1. Clone the repository:
```bash
git clone https://github.com/cbeard06/Python-Programs.git
```

2. Navigate into a project folder:
```bash
cd "Cyber Security Quiz"
```

3. Run the Python file:
```bash
py Cyber_Security_Quiz.py
```
