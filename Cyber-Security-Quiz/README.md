# Cyber Security Quiz

A beginner Python cybersecurity quiz game with 10 multiple-choice questions.

## Features

- 10 cybersecurity questions
- Multiple choice answers
- Score tracking
- Percentage calculation

## Topics Covered

- DNS
- SSH
- TCP vs UDP
- Private IP addresses
- Ransomware
- Social engineering
- Multi-factor authentication
- Brute-force attacks
- Windows networking commands

## How to Run

1. Install Python
2. Open terminal in this folder
3. Run:

```bash
py Cyber_Security_Quiz.py
```
