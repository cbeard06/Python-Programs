# Rock Paper Scissors

This is a simple Python program that allows the player to play Rock Paper Scissors against the computer.

The game uses Python's built-in `random` module to randomize the computer's choices and features a scoreboard after every round so the player can easily keep track of the score.

The game is played first to 3 wins, and the player has the option to continue rematching for as long as they want.

At any point, the user can press `Q` to quit the game.

## Features
- Randomized computer choices
- Score tracking
- Replay/rematch system
- Quit option
- Input validation

- Functions
- Loops
- Conditionals
